# 🚀 Space Mission Explorer

An interactive web application that combines visualizations of our solar system with comprehensive information about historic space missions and exploration.

## 🌟 Features

### Interactive Solar System
- **Real-time Planet Animations**: Watch planets orbit the sun in their respective orbital paths
- **Hover Effects**: Get instant information when hovering over any planet
- **Click for Details**: Click on planets to view detailed information including:
  - Distance from the Sun
  - Planet size
  - Number of moons
  - Day and year lengths
  - Descriptive information

### Mission Information
- **Apollo 11 Moon Landing**: Featured mission with historic details and Neil Armstrong's famous quote
- **Mars Rovers**: Information about Curiosity and Perseverance rovers
- **International Space Station**: Details about continuous human presence in orbit
- **Artemis Program**: Future missions to return humans to the Moon

### Educational Content
- **Rockets Section**: Information about Saturn V, Falcon 9, and Space Launch System
- **Planets Gallery**: All 8 planets with visual representations
- **Moon Exploration**: Details about the Moon and Apollo missions
- **Timeline**: Chronological view of major space exploration milestones from 1957 to 2022

## 🎨 Design Highlights

- **Space-Themed Aesthetic**: Dark space background with purple and blue gradients
- **Glowing Effects**: Neon-style highlights and hover animations
- **Smooth Animations**: Fade-in effects, floating animations, and transitions
- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Interactive Elements**: Hover effects, click handlers, and smooth scrolling

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and canvas for solar system visualization
- **CSS3**: Advanced styling with gradients, animations, and flexbox/grid layouts
- **JavaScript (ES6+)**: Interactive features including:
  - Canvas drawing and animations
  - Event handling and mouse tracking
  - Intersection Observer API for scroll animations
  - Dynamic content updates

## 🎮 Interactivity

### Canvas Interactions
- **Hover**: Move mouse over planets to highlight and view basic info
- **Click**: Click planets to view detailed information
- **Mouse Tracking**: Real-time cursor changes based on hover state

### Navigation
- **Smooth Scrolling**: Click navigation links for smooth section transitions
- **Keyboard Shortcut**: Press ESC to reset planet selection
- **Scroll Animations**: Elements fade in as you scroll
